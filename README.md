# PA Land Balance — Factory Rework Summary

Self-contained interactive page. Open `index.html` locally, or view the published version via
GitHub Pages.

- Factory-by-factory change summary for both factions
- T1 composition matchup matrix + T2 capability deltas
- 3D unit space: speed x range x fair-fight power (hp/metal x sustained dps/metal)

No build step, no dependencies — all 40 unit icons are inlined as data URIs.

Working documents are kept separately and are not part of this repo.
